JavaScript (JS Vanilla)

El lenguaje de programación estándar del desarrollo web cliente

¿Qué es JavaScript y para qué se usa?

JavaScript (JS Vanilla) es un lenguaje de programación interpretado, orientado a objetos y de alto nivel. Se ejecuta directamente en el navegador del cliente sin necesidad de librerías externas. Es el núcleo dinámico de la Web moderna.

HTML (Estructura)

Define el esqueleto, los elementos gráficos y la semántica del documento (botones, capas, textos).

CSS (Estilo)

Controla la presentación visual, colores neón, diseños adaptativos, fuentes y animaciones estéticas.

JS (Comportamiento)

Agrega interactividad dinámica, cálculo de tarifas, manejo de eventos y lógica del terminal.

Conceptos Clave de JavaScript

  • Variables: Espacios de memoria declarados mediante let (reasignable) o const (constante inmutable).
  • Funciones: Bloques de código reutilizables ( function miFuncion() {} o flecha () => {} ) que ejecutan una tarea al ser invocados.
  • Eventos: Interceptores de acciones del usuario como click , hover/mouseenter , o input .
// Ejemplo de Código JS Vanilla 
// Declaración de variables y selector
const btn = document.getElementById('glow-btn');
let clickCount = 0;

// Listener de Evento Click
btn.addEventListener('click', function() {
    clickCount++;
    const display = document.getElementById('count-out');
    display.textContent = `Cargas Neón: ${clickCount}`;
});

jQuery

Librería rápida y concisa para la manipulación del DOM y efectos visuales

¿Qué es jQuery y por qué nació?

jQuery nació en 2006 (creada por John Resig) con el lema "Write less, do more" . Surgió para resolver las incompatibilidades dramáticas entre navegadores de la época (Internet Explorer vs Firefox/Chrome) y simplificar la sintaxis compleja de selección y manipulación del DOM en JS Vanilla.

SINTAXIS BÁSICA DE JQUERY: $("selector").accion();

El símbolo $ es un alias para la función jQuery. Selecciona elementos HTML y les aplica métodos inmediatamente.

VENTAJAS DE JQUERY

  • Sintaxis sumamente corta y directa.
  • Animaciones predefinidas simples ( fadeIn , slideToggle ).
  • Soporte histórico con miles de plugins legados.

DESVENTAJAS HOY EN DÍA

  • Peso extra innecesario (~30KB) si JS Vanilla ya lo hace nativamente.
  • Rendimiento inferior en iteraciones masivas respecto a fetch() o querySelectorAll .
  • Reemplazado en desarrollo moderno por React, Vue y JS ES6+.

JSON (JavaScript Object Notation)

El estándar universal liviano para el intercambio de datos estructurados

¿Qué es JSON y por qué es el estándar web?

JSON es un formato de texto independiente del lenguaje utilizado para transmitir y estructurar datos entre clientes (navegadores) y servidores web o APIs RESTful. Es más liviano y fácil de leer para humanos que XML.

Estructura Básica de Datos

JSON admite tipos de datos primarios: String (siempre entre comillas dobles), Number , Boolean , null , Array [] y Object {} .

// Objeto Literal en JavaScript 
const comision = {
    id: 101,
    modo: "Cyber Glow",
    activo: true,
    precio: 85
};
// Formato Formateado JSON (String) 
{
    "id": 101,
    "modo": "Cyber Glow",
    "activo": true,
    "precio": 85
}

Comunicación Cliente-Servidor: En JavaScript se utiliza JSON.stringify() para convertir objetos JS en cadenas JSON al enviar datos, y JSON.parse() para reconvertir cadenas JSON recibidas en objetos manipulables.

Web Hosting & Dominios

Infraestructura y despliegue global para proyectos web en la nube

¿Cómo se pone una página web en Internet?

Para hacer accesible un sitio web a nivel mundial, se requiere almacenar los archivos (HTML, CSS, JS, imágenes) en un servidor conectado 24/7 ( Web Hosting ) y asociarlo a un nombre recordable ( Dominio Web ).

Hosting Compartido

Varios sitios comparten el mismo servidor y recursos CPU/RAM. Económico pero limitado.

Servidores VPS / Nube

Recursos virtuales dedicados y escalables (AWS, Google Cloud, DigitalOcean).

Vercel (Jamstack Static)

Plataforma cloud optimizada para frameworks y sitios estáticos con despliegue CI/CD automático desde GitHub.

Anatomía de un Nombre de Dominio

app. cyberartcomisiones .com
Subdominio Nombre Raíz (Domain Name) TLD (Top Level Domain)
